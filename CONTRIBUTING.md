# Contributing

Issues and pull requests are welcome on [OpenRoyleAl/Alfred.report](https://github.com/OpenRoyleAl/Alfred.report).

1. Fork and branch from `main`.
2. Keep secrets out of commits (use `.dev.vars` locally).
3. Run `npm run typecheck` and `npm test` before opening a PR.
4. Prefer small, focused changes over drive-by rewrites.

Product feedback for the live site: [alfred.report](https://alfred.report).
